# Fret & Key Maestro

Интерактивный музыкальный инструмент для визуализации гамм и ладов на гитарном грифе и фортепианной клавиатуре. Это приложение разработано как полезный ресурс для музыкантов любого уровня.

## Возможности

-   **Два инструмента:** Переключайтесь между гитарным грифом и фортепианной клавиатурой.
-   **Выбор тональности и гаммы:** Выберите любую корневую ноту и одну из множества гамм или ладов (мажор, минор, пентатоника и др.).
-   **Интерактивная подсветка:** Ноты, входящие в выбранную гамму, ярко подсвечиваются. Корневая нота отмечена особым образом.
-   **Воспроизведение звука:** Нажмите на любую ноту, чтобы услышать её звучание (используется библиотека Tone.js).
-   **Настройка гитарного строя:** Выберите один из популярных гитарных строев (Standard, Drop D, Open G и т.д.).
-   **Настройки отображения:** Возможность показать все ноты на грифе или только ноты гаммы, а также включить/выключить отображение названий нот.
-   **Адаптивный дизайн:** Интерфейс полностью адаптивен и отлично работает как на компьютерах, так и на мобильных устройствах.
-   **Темная тема:** Стильный темный интерфейс для комфортного использования.

## Технологический стек

-   **Фреймворк:** React
-   **Язык:** TypeScript
-   **Сборщик:** Vite
-   **Стилизация:** Tailwind CSS
-   **Компоненты интерфейса:** shadcn/ui
-   **Работа со звуком:** Tone.js
-   **Роутинг:** React Router

## Начало работы

Чтобы запустить проект локально:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repository-url>
    cd <repository-directory>
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер для разработки:**
    ```bash
    npm run dev
    ```
    Приложение будет доступно по адресу `http://localhost:8080`.
