# Fret & Key Maestro

Интерактивный музыкальный инструмент для визуализации гамм и ладов на гитарном грифе и фортепианной клавиатуре. Это приложение разработано как полезный ресурс для музыкантов любого уровня.

## Возможности

-   **Пять инструментов:** Переключайтесь между акустической гитарой, чистой электрогитарой, перегруженной гитарой (Distortion), бас-гитарой и фортепиано.
-   **Подключение реальной гитары:** Подключите свою физическую гитару через микрофон и наблюдайте, как извлекаемые вами ноты отображаются на виртуальном грифе и клавишах в режиме реального времени.
-   **Режимы гамм и аккордов:** Визуализируйте не только гаммы, но и десятки типов аккордов (мажорные, минорные, септаккорды, нонаккорды и др.) по всему грифу до 24 лада.
-   **Арпеджиатор:** Прослушивайте ноты гаммы или аккорда последовательно с настраиваемым темпом и направлением.
-   **Генератор прогрессий по эмоциям:** Создавайте последовательности аккордов на основе настроения (радость, грусть, эпичность, таинственность).
-   **Кварто-квинтовый круг:** Интерактивный инструмент для понимания взаимосвязей между тональностями и быстрого выбора основной ноты.
-   **Максимальный набор строев:** Поддержка множества гитарных строев, включая пониженные (Drop), открытые (Open), а также 7-ми и 8-ми струнные конфигурации.
-   **Выбор тональности и гаммы:** Выберите любую корневую ноту и одну из множества гамм или ладов (мажор, минор, пентатоника, экзотические лады).
-   **Интерактивная подсветка:** Ноты, входящие в выбранную гамму или аккорд, ярко подсвечиваются. Корневая нота отмечена особым образом.
-   **Воспроизведение звука:** Реалистичное звучание инструментов благодаря использованию семплов (Tone.Sampler). Нажмите на любую ноту, чтобы услышать её звучание.
-   **Настройка гитарного строя:** Выберите один из популярных гитарных строев (Standard, Drop D, Open G и т.д.).
-   **Настройки отображения:** Возможность показать все ноты на грифе или только ноты гаммы, а также включить/выключить отображение названий нот.
-   **Адаптивный дизайн:** Интерфейс полностью адаптивен и отлично работает как на компьютерах, так и на мобильных устройствах.
-   **Темная тема:** Стильный темный интерфейс для комфортного использования.

## Технологический стек

-   **Фреймворк:** React
-   **Язык:** TypeScript
-   **Сборщик:** Vite
-   **Стилизация:** Tailwind CSS
-   **Компоненты интерфейса:** shadcn/ui
-   **Работа со звуком:** Tone.js
-   **Роутинг:** React Router

## Начало работы

Чтобы запустить проект локально:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repository-url>
    cd <repository-directory>
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер для разработки:**
    ```bash
    npm run dev
    ```
    Приложение будет доступно по адресу `http://localhost:8080`.
